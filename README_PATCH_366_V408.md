# Patch 366 · V408 · familles culinaires et alternatives

Ce patch remplace entièrement le patch 365 non uploadé.

Il conserve les corrections cumulatives précédentes :

- « Une autre idée » produit une nouvelle proposition ;
- les idées enregistrées peuvent être rouvertes ;
- les préférences récentes et intentions orientent le résultat ;
- saisie libre d'un ou plusieurs ingrédients ;
- aucune nouvelle requête Supabase et aucun nouvel appel au catalogue.

Il ajoute sept familles culinaires précises avec quatre alternatives chacune :

- pizza-toast / croque-pizza jambon-tomate-fromage ;
- rumsteck, petits pois et oignon ;
- fromage à pâte molle, farine et œufs ;
- pommes de terre, viande hachée et oignon ;
- appareil salé au poulet, œufs, farine, beurre et crème ;
- desserts chocolat, beurre, sucre, farine et œufs ;
- thon, poivron et oignon.

Les synonymes usuels sont reconnus (toast, pain complet tranché, sauce ou purée de tomate, brie/camembert, rumsteck/bavette/faux-filet, steak haché, blancs/escalopes de poulet, chocolat dessert, etc.).

Contrôles effectués : syntaxe JavaScript, identité racine/`www`, 42 scénarios intention × ingrédients, structure de l'archive.
