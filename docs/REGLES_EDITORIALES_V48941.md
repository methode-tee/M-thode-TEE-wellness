# Règles éditoriales V489.4.1

La présence d'un aliment dans CIQUAL ne lui donne jamais le droit d'être proposé comme repas.

Le cerveau TEE conserve tout CIQUAL pour :
- nutrition ;
- compréhension du journal alimentaire ;
- mémoire ;
- substitutions ;
- proximité alimentaire ;
- coût.

Le planner utilise seulement :
- recettes TEE ;
- plats complets stricts ;
- plats composés CIQUAL ;
- repas du catalogue culinaire TEE publiés.

Les assiettes TEE génériques sont issues de matrices culinaires whitelistées.
Les plats culturellement spécifiques ne sont pas promus automatiquement au premier plan.

Une publication automatique exige une résolution CIQUAL forte de tous les composants obligatoires.
